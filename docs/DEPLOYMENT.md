# Deployment Guide

## 1. Local Setup (Zero Cost)
The system runs completely offline on a normal laptop using:
- Backend: FastAPI + Uvicorn + SQLite
- Frontend: Vite React SPA

## 2. Free-Tier Cloud Deployment (Optional)
- **Backend**: Render.com or Railway.app free web service tier for FastAPI.
- **Frontend**: Vercel or Netlify for Vite React frontend static hosting.
- **Database**: Included SQLite or free ElephantSQL / Render PostgreSQL.
